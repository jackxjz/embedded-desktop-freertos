# 基于 ESP32 的简易 FreeRTOS 操作系统

中文 | [English](README.en.md)

本项目为 ESP32-S3 开发板上的 FreeRTOS 桌面模拟器，集成图形用户界面（LVGL）、文件系统、网络同步、电源管理等核心功能，旨在展示嵌入式多任务系统与交互式应用的设计能力。

项目为 **2026 电子科技协会嵌入式组考核** 作品。

## 主要特性

- **图形界面**：基于 LVGL 构建桌面、应用图标、窗口管理器及软键盘。
- **文件系统**：SPIFFS 支持文件新建、删除、编辑及唯一性校验。
- **账户管理**：本地账户注册/登录，密码错误锁定机制，记住密码（NVS 加密存储）。
- **网络同步**：Wi-Fi 自动连接，NTP 同步时间，断线重连。
- **电源管理**：超时自动息屏 + 主动手动息屏，息屏时间可配置（10/20/30秒）。
- **系统设置**：光标大小调节，参数 NVS 持久化，即时生效。
- **多任务调度**：FreeRTOS 双核任务划分（界面响应、网络后台、电源监控等）。
