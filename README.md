# 基于 ESP32 的简易 FreeRTOS 操作系统

中文 | [English](README.en.md)

本项目为 ESP32-S3 开发板上的 FreeRTOS 桌面模拟器，集成图形用户界面（LVGL）、文件系统、网络同步、电源管理等核心功能，旨在展示嵌入式多任务系统与交互式应用的设计能力。

项目为 **2026 电子科技协会嵌入式组考核** 作品。

## 主要特性

- **图形界面**：基于 LVGL 构建桌面、应用图标、窗口管理器及软键盘。
- **文件系统**：SPIFFS 支持文件新建、删除、编辑及唯一性校验。
- **账户管理**：本地账户注册/登录，密码错误锁定机制，记住密码（NVS 加密存储）。
- **网络同步**：Wi-Fi 自动连接，NTP 同步时间，断线重连。
- **电源管理**：超时自动息屏 + 主动手动息屏，息屏时间可配置（10/20/30秒）。
- **系统设置**：光标大小调节，参数 NVS 持久化，即时生效。
- **多任务调度**：FreeRTOS 双核任务划分（界面响应、网络后台、电源监控等）。

## 故障排除

### 绘图应用保存时闪屏

**现象**：点击绘图应用的保存按钮时，屏幕出现明显闪烁；绘制的像素点越多，闪屏越严重、持续时间越长。

**原因分析**：

1. **主线程阻塞**：`drawing_save()` 函数在 LVGL 主线程（事件回调）中直接执行保存逻辑，遍历 480×320 = 153,600 个像素，对每个非白像素调用一次 `fprintf`。当绘制内容较多（数万像素）时，数万次文件系统调用会阻塞主线程数百毫秒甚至数秒。
2. **Flash 写入开销**：SPIFFS 写入 Flash 时可能触发缓存未命中，进一步加剧 CPU 停顿；同时 LVGL 刷新依赖 VSYNC 或定时器，主线程阻塞导致刷新中断，阻塞结束后补刷产生视觉闪屏。

**解决方案**：

- 将保存操作移至 **FreeRTOS 后台任务**，避免阻塞 LVGL 主线程。ESP32-S3 双核可分别处理界面渲染和文件写入。
- 使用 **8KB 内存缓冲区批量写入**，缓冲区满后再调用 `fwrite` 一次性写入 Flash，大幅减少系统调用次数。
- 保存期间显示“保存中...”遮罩，防止用户继续操作；保存完成后通过 `lvgl_port_lock` 安全回调 UI 显示结果。
- 采用 **二进制存储格式**（每个像素 6 字节，含 x/y 坐标与颜色值），数据量约为文本格式的 1/3，写入速度更快。

### 文件管理器相关崩溃

- **账号列表刷新崩溃**：刷新列表时未重置选中状态，操作已销毁对象导致野指针访问。修复：刷新时重置选中状态（参见 v4.2 改进）。
- **文件编辑器关闭崩溃**：消息框回调中使用 `lv_obj_get_parent()` 获取对象层级错误，导致访问无效地址。修复：改用 `lv_event_get_current_target()` 获取当前事件目标（参见 v4.2 改进）。
- **内存泄漏**：账号列表清空或销毁时未释放 `user_data` 动态内存。修复：正确释放 `user_data`（参见 v4.2 改进）。

### 记住密码状态不一致

**现象**：登录页面“记住密码”复选框状态与 NVS 中实际存储的凭证不一致。

**原因与修复**：登录成功后未同步更新 `is_remeber` 状态变量，导致页面状态与存储数据不匹配。修复：登录成功后同步更新该变量（参见 v4.2 改进）。取消“记住密码”时自动清除 NVS 中已保存的账号凭证（参见 v4.1 改进）。

### 系统设置不生效

**现象**：修改光标大小或息屏时间等设置后，重启设备配置丢失或修改未即时生效。

**原因与修复**：参数未持久化存储至 NVS，或修改后未通知相关模块刷新。修复：统一封装 NVS 读写接口，参数变更后即时写入 NVS 并广播刷新事件。

### 网络时间同步失败

**现象**：Wi-Fi 连接成功后时间未同步，或断网重连后时间未更新。

**原因与修复**：NTP 同步完成后未更新桌面状态栏；断网重连后未自动重新同步。修复：同步完成后主动刷新显示；实现断线自动重连与重连后自动同步机制。
